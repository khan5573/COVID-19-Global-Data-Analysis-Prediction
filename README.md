# COVID-19-Global-Data-Analysis-Prediction
## 📌 Project Overview

The **COVID-19 Global Data Analysis & Prediction** project is a data analytics and machine learning-based project designed to analyze the global impact of the COVID-19 pandemic.

This project focuses on exploring worldwide COVID-19 data, identifying trends in confirmed cases, deaths, and active cases, and understanding how the pandemic affected different countries over time.

Using Python, SQL, Machine Learning, and Data Visualization techniques, this project transforms raw COVID-19 data into meaningful insights that help understand global pandemic trends and patterns.

## 🎯 Project Objectives

- Analyze global COVID-19 cases and death statistics.
- Identify the countries with the highest confirmed cases.
- Analyze countries with the highest death counts.
- Explore active COVID-19 cases across different countries.
- Understand monthly COVID-19 trends.
- Perform data cleaning and preprocessing.
- Use SQL queries for data analysis.
- Apply Machine Learning for trend analysis and future case estimation.
- Create professional charts and visualizations.
